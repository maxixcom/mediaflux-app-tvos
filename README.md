# mediaflux-app-tvos

Приложение dodocast для Apple TV (MF-86; устройство — `../mediaflux-docs/docs/APPS.md`). Работа идёт в ветке
`feature/mf-86-apps` (как во всех репозиториях MF-86).

Две цели (`project.yml`, XcodeGen):
- **`DodocastTV`** — клиент (MF-90, Э3, в работе): выбор сервера, вход по коду, устройство; дальше каталог, плеер с
  позицией, поиск и настройки. Код — `DodocastTV/`, GraphQL — Apollo iOS 2.5 (`scripts/codegen.sh`), тесты —
  `DodocastTVTests/`. Бренд — только в `DodocastTV/Brand`.
- **`Spike`** — пробное приложение Э0 (MF-87, MF-97) без изменений, для замеров плеера. Ниже — про него.

Сборка и запуск: `scripts/sim.sh` и `scripts/device.sh`, цель — `TARGET=DodocastTV` (по умолчанию) или `Spike`.
Клиент на локальной среде — только в симуляторе: `scripts/sim.sh /tmp/run.log -server http://localhost:17091`.

## Пробное приложение (Spike): что умеет

- **«Потоки».** Тестовые материалы tst из `Spike/Config.swift`.
  - Перед запуском приложение берёт свежий конфиг у стримера и играет выбранную упаковку: fMP4 или TS.
  - Плеер штатный (`AVPlayerViewController`), главы — маркеры навигации tvOS.
  - **Картинки плиток глав (MF-97)** вырезаются из превью-спрайтов стримера (`/preview/{code}/…`,
    `Spike/PreviewSprites.swift`). Тайл выбирается тем же правилом, что на витрине, поэтому кадр главы
    совпадает с сайтом. Старт воспроизведения картинок не ждёт: маркеры ставятся сразу с названиями и
    переназначаются, когда картинки готовы. Нет превью — плитки остаются с названиями.
  - Раз в 10 с в журнал и на экран пишется, сколько скачано, битрейт и ошибки.
- **«Вход».** Вход по коду в Keycloak tst (клиент `mediaflux-app-tvos`, до 18.11.2026 — `mediaflux-tv`), QR для телефона.
  - Утверждения токена показываются, сами токены — нет.
  - Кнопки «Обновить» и «Отозвать».
  - Refresh-токен и идентификатор установки хранятся в Keychain.

## Сборка

Нужны Xcode с платформой tvOS и `xcodegen` (`brew install xcodegen`). Проект `DodocastTV.xcodeproj`
генерируется из `project.yml` и в git не лежит.

```bash
xcodegen generate
```

## Запуск

**Симулятор.** Скрипт собирает, ставит и запускает приложение; журнал пишется в файл:

```bash
TARGET=Spike scripts/sim.sh /tmp/run.log -autoplay media:KcXy8AGnf9:mp4 -seek-to 12
```

**Сценарий — аргументами запуска**, потому что пультом из терминала не нажмёшь:

| аргумент | что делает |
|---|---|
| `-autoplay вид:код:упаковка` | сразу открыть поток |
| `-seek-to N` | через 8 с перемотать на N-ю секунду |
| `-pause-after N` | поставить на паузу через N секунд после старта |
| `-resume-after N` | продолжить после N секунд паузы |
Строки журнала приложения начинаются с `[MF87]`.

**Живой Apple TV.** Нужны:
- Apple ID в Xcode (Personal Team);
- сопряжение телевизора (Xcode → Devices and Simulators);
- режим разработчика на Apple TV.

Подпись бесплатной команды живёт 7 дней.
